# Contributing to `@textmode/og`

Thank you for helping improve `@textmode/og`.

Start with the shared [code contribution guide](https://code.textmode.art/docs/contributing/code) for repository
routing, setup, workflow, documentation, testing, asset, and review expectations.

## Quick start

```bash
npm ci
npm run check
```

Create a focused branch from `dev` and open the pull request against `dev`. Discuss public API changes, rendering,
packaging, browser support, or bundled assets in an issue or Discussion before implementation.

Add or update tests when behavior changes. Test rendering changes in a real browser and include screenshots for
visual changes. Keep generated Open Graph output deterministic and preserve existing destinations when generation
fails.

Read the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately by following
[SECURITY.md](SECURITY.md), not through a public issue.

Need help? [Open an issue](https://github.com/textmode-art/og/issues) or
[join Discord](https://discord.gg/sjrw8QXNks).
